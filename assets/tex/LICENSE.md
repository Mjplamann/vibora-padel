# assets/tex — tileable detail normal maps

| File | Source | Licence |
|---|---|---|
| `orange-peel-normal.webp` | @pmndrs/assets 1.7.0 `normals/0027.webp.js` | CC0 1.0 (as distributed by @pmndrs/assets) |
| `grit-normal.webp` | @pmndrs/assets 1.7.0 `normals/0015.webp.js` | CC0 1.0 (as distributed by @pmndrs/assets) |
| `grain-normal.webp` | @pmndrs/assets 1.7.0 `normals/0004.webp.js` | CC0 1.0 (as distributed by @pmndrs/assets) |

The files are the package's base64 payloads decoded to plain WebP (512 x 512) without any other
change. @pmndrs/assets (https://github.com/pmndrs/assets) is published under CC0 1.0 Universal; its
README points to https://github.com/emmelleppi/normal-maps for previews of the normal maps. That
repository carries no separate licence file, so the CC0 grant of @pmndrs/assets is the licence on
record for these three files.

Used as world-space triplanar detail normals (`src/render/detailMaps.js`): orange-peel powder coat on
the court steel, grit on concrete / walls / bark, grain on the bench wood.
